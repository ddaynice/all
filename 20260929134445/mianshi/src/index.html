各分类进度

记忆盒分布

怎么用

  1. 右上角 ⚙ 配置 AI 接口（OpenAI 兼容，如 DeepSeek / 智谱 GLM / Kimi）
  2. 出题后凭记忆写下答案，点「AI 判卷」：AI 会对比你整理的标准答案打分并点评
  3. 展开标准答案对照，按建议记分（忘了 / 模糊 / 掌握）进入间隔重复
  4. 不想写答案时点「直接看答案」走传统自评模式

间隔重复规则

每张卡有一个记忆盒 Box 0–5。评为「掌握」升一级、出现间隔变长；「模糊」停在原级；「忘了」直接掉回 Box 0，明天之前会反复出现。

  • Box 0 → 立刻再来
  • Box 1 → 1 天后
  • Box 2 → 2 天后
  • Box 3 → 4 天后
  • Box 4 → 7 天后
  • Box 5 → 15 天后

快捷键

  • Ctrl+Enter AI 判卷
  • 空格 显示答案 / 下一题
  • 1 忘了　2 模糊　3 掌握
  • E 编辑当前卡片

进度和你的修改都存在浏览器本地（localStorage），换浏览器或清缓存会丢，记得偶尔在统计页导出备份。
