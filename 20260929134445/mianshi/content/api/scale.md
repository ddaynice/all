#### 3.**getter和setter方法**

**在class里面定义的var，会同时****默认生成****getter函数和setter函数**

比如 var y = 2，会有 def **y**:Int 和 def **y_=** (y:Int):Unit 两个函数其中

---

def **y**:Int是一个属性声明，y是属性的名字，int是该属性的类型，这是getter方法

def **y_=** (y:Int):Unit 这是一个setter方法的声明，用于设置属性 `y` 的值。`y_=` 是setter方法的特殊命名约定，其中下划线 `_` 后缀表示这是一个setter

`y: Int` 是setter方法的参数列表，表示你将要设置的新值，而 `Unit` 是返回类型

**属性名_=**作为一个整体作为方法名动态生成

---

举个栗子

a.money_=(200)

a是类对象，money_=是方法名，200是参数

使用scala自带的Bean 属性（@BeanPropetry），可以自动生成规范的 setXxx/getXxx 方法

- [ ]

**Scala 并不推荐将属性设为 private，并为其显示的设置public 的 get 和 set 方法的做法。**

**getter方法和setter方法的意义在于控制类中私有对象的数据**。

Scala 类的主构造器函数的形参包括三种类型：没有任何修饰、var 修饰、val 修饰

（1）**未用任何修饰符修饰，这个参数就是一个局部变量**，等价于被private[this] var修饰（无set和get）

（2）var 修饰参数，作为类的成员属性使用，可以修改（有get、set）

（3）val 修饰参数，作为类只读属性使用，不能修改（有get，无set）

### **特质****☆☆**

特质是scala中特有的，因为再scala中没有接口，所以特质是接近java中的接口

与接口不同的是，**它还可以定义属性和方法的实现  ？？**

特质可以让类从继承单一的父类变成，继承多个父类，也就是说原来我能有一个爸爸，现在我就能有多个爸爸了

所以这就是实现了多继承

特质的定义的方式与类相似，除了不能拥有构造参数，但它使用的关键字是 trait。

- [ ]

所以特质一旦被定义，既可以由类来实现，再scala中实现称为”**混入（mixin）**

依旧使用关键字extends

**混入格式**

class B extends A {...}

**混入多个格式**

利用**with关键字**：

class D extends A with B with C {...}

所以特质就是抽象类+接口的组合

**那么特质的成员呢？**

特质的成员可以是抽象的，而且不需要使用abstract声明

重写特质的抽象方法无需override，但是**多个特质重写同一个特质的抽象方法需override**

特质继承抽象类时，重写的方法要用abstract override修饰

特质混入特质以及构造对象时混入对象
