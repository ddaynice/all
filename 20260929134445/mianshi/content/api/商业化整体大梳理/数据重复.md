`-- 重复率 = (总记录数 - 去重记录数) / 总记录数
SELECT imp_date,
    COUNT(
`*`) as total_count,
    COUNT(DISTINCT advertiser_id, project_code, xs_buying_type) as distinct_count,
    (COUNT(
`*`) - COUNT(DISTINCT advertiser_id, project_code, xs_buying_type)) / COUNT(*) as duplicate_rate
FROM ads_pub_ad_ams_execution_income_df
WHERE imp_date = '20240513'
``GROUP BY imp_date`

##### **自动化处理流程**

**问题自动修复流程**:

代码块

**折叠代码块**

**复制**

`-- 自动化去重处理CREATE PROCEDURE auto_deduplicate_data(IN target_date STRING)
BEGIN
    -- 1. 检测重复数据
    DECLARE duplicate_count INT;
    SELECT COUNT(*) INTO duplicate_count
    FROM duplicate_detection_view WHERE imp_date = target_date;
    -- 2. 执行去重
    IF duplicate_count > 0 THEN
        CALL execute_deduplication(target_date);
        -- 3. 验证结果
        CALL verify_deduplication_result(target_date);
        -- 4. 发送通知
        CALL send_deduplication_report(target_date, duplicate_count);
    END IF;
``END;`
