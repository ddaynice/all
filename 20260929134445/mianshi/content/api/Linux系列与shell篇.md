什么事shell?

Shell俗称壳（用来区别于核），是指“为使用者提供操作界面”的软件（command interpreter，命令解析器）。它类似于DOS下的COMMAND.COM和后来的cmd.exe。它接收用户命令，然后调用相应的应用程序。

**bash和sh还是有很多不同的，一方面，bash扩展了一些命令和参数，另一方面，bash并不完全和sh兼容**

**linux shell需要掌握这些概念**

### shell退出命令

shell退出（运行结束）时，都会返回一个比较小的整数值给调用（使用）它的程序，**这就是命令的退出状态（exit statu）**。

**如果程序想在中间退出，还可以使用exit 0**

按照惯例来说，退出状态为 0 表示“成功”；

也就是说，程序执行完成并且没有遇到任何问题。

除 0 以外的其它任何退出状态都为“失败”。

之所以说这是“惯例”而非“规定”，是因为也会有例外，比如 diff 命令用来比较两个文件的不同，

对于“没有差别”的文件返回 0，对于“找到差别”的文件返回 1，对无效文件名返回 2。

### ** shell内置命令和外部命令**

**外部命令，有时候也被称为文件系统命令，是存在于bash shell之外的程序。**它们并不是shell程序的一部分。**外部命令程序通常位于/bin、/usr/bin、/sbin或/usr/sbin中。**

如上ps 就是一个外部命令。你可以使用 which 和 type 命令找到查看它。**内建命令和外部命令的区别在于前者不需要使用子进程来执行。它们已经和shell编译成了一体，作为shell工具的组成部分存在。不需要借助外部程序文件来运行。**
