### 大数据工程师

#### 1.基础：

**数据抽取（熟练使用 Sqoop、DataX 等工具从 MySQL 抽取数据到大数据平台）**

**数据同步（掌握基于 binlog 的增量数据同步，如 Canal 工具的使用）**

**批量数据处理（能高效编写批量导入、导出 MySQL 数据的脚本，适配大数据场景下的海量数据迁移）**

**MySQL 与大数据组件的交互（了解 MySQL 作为数据源或结果存储，与 Hive、Spark 等组件的协同工作方式）**

#### 2.进阶

**1.分库分表下的数据整合（能处理 MySQL 分库分表场景下，数据向大数据平台的整合与统一分析）**
**2. 复杂数据清洗逻辑在 MySQL 与大数据平台的协作（部分简单清洗在 MySQL 完成，复杂清洗在大数据平台处理，掌握两者间的高效衔接）**
**3. 基于 MySQL 的数据服务搭建（将大数据分析结果，通过 MySQL 对外提供低延迟的数据查询服务，涉及数据落地后的索引、缓存等优化）**

### 为什么要有数据库？

数据库就是存储，存的是要长久保存的数据，类似一个储物柜，找东西的时候就能找的明白

### 数据库三大核心成员

DB-数据库，Database

DBMS-数据库管理系统

SQL-结构化查询语言

这三个是依赖关系，数据库就是储物柜，管理系统就是储物柜的管理员，比如mysql和oracle这些软件，负责建库，建表，查数据，sql就是和管理员沟通的语言！

#### 那么哪个数据管理系统最牛？

这是2025年的排行

1

Oracle

收费、功能强、稳如老狗，能扛超大数据量

大型企业 “御用”，比如银行、电信（不差钱的主）

2

MySQL

开源免费、轻量快、好上手

互联网公司 “宠儿”，淘宝、美团、抖音都用它

3

SQL Server

微软家的、跟.NET/C# 超搭，Windows 环境友好

微软生态企业常用，比如一些国企、Windows 开发团队

4

PostgreSQL

开源、符合 SQL 标准、支持复杂功能

对数据质量要求高的场景，比如科研、数据分析

5

SQLite

嵌入式小数据库、不用装不用配，直接用

手机 APP、小工具，比如微信聊天记录就存在 SQLite 里
