## 一、交易哲学（③为主）

1. **规律做单，不做无脑跟单**（②00:44）："咱们一直在说的是规律做单"——规律是提前可知的；
   跟单没有自己的信心，"都是在赌它对"，过程中拿不住。
2. **行情周而复始套用相似走势**（②18:06）："行情在某种程度上就是周而复始地套用某一个走势，
   只不过级别可以更小"——同一形态可涨200点也可涨20万点。这是他手工形态对照的理论根基。
3. **二八定律与幸存者偏差**（③）：亏的人不说，赚的人宣扬，感知比例从2:8变成8:2；
   期货大赛盈利者仍只有20%。
4. **会技术≠赚钱，不会技术≈难赚钱**（③05:15）：技术是方向性的，趋势技术震荡期失效；
   "你靠它赚的也会靠它赔"。
5. **看错正常，做错不行**（②04:33）："你可以看错，但尽量不要做错"——看错的单子靠操作
   扭转成不亏/小赚，就是好的操作。
6. **时间观**（③）：交易可以做一辈子，10年才刚开始；以5年为单位做计划，
   黄金5年+40%=年化8%，3500买+70%=年化13-14%。

## 二、市场结构认知（①②）

7. **分水岭体系**（核心概念，①②均出现）：
   - 定义：本轮下跌的起点/下跌前最后一个高点（①11:38"这个分水就是这一轮下跌的起点"）、
     关键前高前低水平线（白银54.7"小的分水"）
   - 判定：**站上分水岭 → 前期下跌定性为洗盘**，回调后再涨 → 持有；
     **未站上再跌回 → 仍属下跌节奏**，偏向悲观（可能继续破前低甩到3700/3600）
   - 只要打破分水，"最少是一个不大不小的反弹出现，或者回踩次低的反弹出现"（②12:54）
8. **大跌大弹规律**（②00:47）："跌破前面低点没有多深的距离，它就会反弹上来"——
   所以**处理方式是等它反弹上来再处理，不是跌破时割肉**。跌破3940后"扫掉把3940当止损的人，
   现在开始下一轮反弹"。
9. **通道有效性**（②02:14）：高点降低、低点降低的下降通道，价格打到通道位置就结束，
   "说明这个通道是有规律的、有意义的，可以当参考"。
10. **两种上涨**（①01:05，决定持有/减仓）：
    - 快速小幅持续上涨（波段小回调浅）="短期拉涨出货" → 减仓
    - 慢速上涨（耗时长幅度小、涨涨跌跌）= 健康 → 持有
11. **回调时间/空间的统计**（①纳指案例）：2000年起跌8年，此后每轮回调不深快速修复，
    最近一轮2021年约1年；回调比例照搬前段（25%）→ 推算目标价；
    大盘历轮回调天数120/170/160天 → 判断回调末端。

## 三、入场系统

12. **止跌确认前不动手**（①05:02）："下跌没有止跌，就不能认为前低一定撑住；
    只有它什么时候止跌，才可能以前低当止损去搏"。
13. **最低回调深度门槛**（②17:51）：纳指回调11%不够——"给我20%的空间，我才有搏的欲望"；
    每个品种有自己的深度门槛，没给到机会就不做（"直接涨了，OK，那不属于我的交易"）。
14. **浅回调/深回调两种入场**（②12:05）：预期反弹后观察回踩深浅——
    浅回调只能激进进场（半仓一成半），深回调可以等次低、价格更优美。
    "不能强求行情一定暴涨不回调，只要它没过分水，再下来完全有可能"。
15. **盈亏比≥3:1**（②14:47 原油案例）：均价75-76，上方120-150（+60~70%），
    下方破新低约-20% → 3:1基础盈亏比，"完全值得做，大不了就亏，没有谁做单不亏"。
16. **手续费纪律**（②06:35）：费用占单笔利润控制在 **5% 以内**，10%就已非常高——
    这也是实物金无杠杆只做长线的原因（一次买入赚30-40%，费率1%可接受）。

## 四、持仓与出场

17. **保本单机制**（①02:19、②13:06，最标志性的操作）：
    突破小的分水 → 把止损从入场位（前低45）**挪到入场价** →
    "再回来就出掉，不亏钱；相当于没用多少成本就博大赚"——
    "大赚你不一定能守到，但亏不亏你能决定"。
18. **目标位规则**：没破前高之前，一切上涨都只是反弹；基础目标=前高（如BTC 86000），
    更远看88000，"到这个范围就减仓出场，这笔短线就结束"。
19. **减仓条件**：快速拉升在前高/长上影处减仓（①4200以上"涨得比较高"再减；
    ②茅台跳空高开斜率垂直减1/3）。
20. **反弹vs反转要分清**（②24:17）："你预计的是反弹，就不要搏新高；
    预计有可能反转，才可以搏一搏"——弱势品种（五粮液跌70%）只搏反弹到200，不搏新高。

## 五、仓位管理

21. **剧本化分批**：1/2+1/2（兼顾"回撤浅直接涨"和"回撤深再涨"，明确不用1/3定投，
    因为反弹时1/3仓位"不太顶"）（①06:29）。
22. **阶梯加仓**（②16:39 原油）：现持60% → 回到80下方买20% → 破前低60多再买20%
    → "无论什么时候启动，手里60%/80%都可接受"。
23. **加仓位置纪律**（②03:09）：加仓部分放在震荡区间的低位；"不会把低位部分先砍掉、
    跑到更低位再补回来——这肯定是错误思路"，因为加仓决策时就要接受"可能没有更好价格"。
24. **短线/长线组合**（②25:41 茅台）：明确止损+右侧入场=短线条件 → 1/3做短线，
    2/3留作长线（可能慢慢转长线）；短线落袋后长线部分"扔着"。
25. **金字塔加仓**（②21:06 大盘）：前低之上、前高之下的区间内金字塔式加仓，博下一轮。

## 六、风控（③思维篇）

26. **风险评估决定资金量**（③16:47）：亏5%就受不了的人，投入资金造成的亏损就应低于5%；
    能承受20%的人亏15%以内算合理。
27. **强制关机线**（③18:25）：总资金缩水15% → "强制关机、强制下线、强制停手"，
    承认失败，换其他投资方式。
28. **多元化=对冲心态**（③19:04）：不要把所有钱放一个篮子；多品种有亏有赚，
    "整体微微赚微微亏"就是投资的最终目的；"要以投行的角度去成长"。
29. **杠杆=压缩时间=赌**（③16:03 久留美反面教材）：把时间成本和资金成本压缩到极致
    去搏暴力拉伸，"本质上这就是赌"——心理压力下不可能长期盈利。
30. **死拿也是策略的一环**（③07:08）：低价筹码+无杠杆+风控匹配时，死拿的结果
    常好过频繁做差价（"多做一次开仓=多一次风险"）；但高位死拿不回本的情况也存在。

## 七、计划失效的处理与时间档位（④新增）

31. **买入时就预设三档时间剧本**（④01:10 黄金案例）：半年回撤修复后直接涨 / 拖到两年 /
    拖到四年——依据是近20年黄金周线月线结构："一轮大涨 → 接近四年的调整 → 超级大涨，
    过程中都是两年的调整"。当前回调不属于半年级，就往两年/四年档归类。
32. **计划失效≠割肉**（④00:25）：跌破了分水、原计划失败，但买的是实物金无杠杆 →
    "买它的目的是资金配置"，拿住，把预期从半年档改到两年/四年档。
33. **下跌斜率衰减规律**（④04:38）：深度回调剧本是"越跌越慢"——一年下跌在更长周期图上
    表现为快速下跌+漫长反弹+再下跌的震荡组织，"往两年拖其实也是在拖一年而已"。
34. **跨品种领先/滞后关系**（④06:45）：白银跌得快、反弹也快，**看白银做黄金**——
    白银突破前高 → 预期黄金也能破4700 → 仓位不减；白银反弹后快速回踩前低 →
    黄金反弹到4700附近做减仓处理。"白银走的快，能提前一两周给提示"。
35. **分批 vs 一次性**（④11:02）：分批的意义在于价差——预计入场区间内价差大（如BTC
    八万到七万五差几千点）才分批；价差小（就差一千点）一次性买入更合适。
36. **顶部追涨的空间门槛**（④09:10）：纳指2700-3100只有15-20%空间，"掐头去尾也就10%"
    → 顶部追涨不参与；等跌破2700进入买点区域（2600以下-2300以上），盈亏比3:1~4:1才做。
37. **跳空加速=短线见顶信号**（④12:45 茅台案例）：斜率接近垂直后再次跳空高开
    （"涨无隔涨"）→ 类比上证指数10月8号 → 短期必有回调 → 1500以上继续冲就减仓/跑路；
    另一种结局是横盘蓄力 → 继续拿。"蓄力完拉升，拉升完蓄力"，蓄力时间远超上涨时间。
38. **收敛形态选方向**（④15:03 白酒/白银）：整体向内压缩的三角形"收到结尾就要选方向"，
    结合位置倾向向上爆发——白银长期压缩也是他敢于低位重仓的依据。

## 八、思维篇——薛定谔的猫（⑤新增）

39. **赚钱=周期净值结算，不看单笔得失**（⑤00:26）：目的是净值增加——"做交易是1000笔订单甚至无数笔订单的总和，最终（退出市场）结算时能搬砖撤离就赚钱"；某一单的得失跑出来，看一年结算赚多少百分比。
40. **浮亏≠亏，割肉出场才确认爆亏**（⑤02:29）：没出场之前只是浮亏/套牢；"到某个位置我要割肉了，亏损出场，变成净值减少的状态，那才是真正亏了"。做的周期越大，先浮亏越容易——黄金4000买、跌回持仓价，中途平调与否是两个结局。
41. **薛定谔的猫：开盒之前行情是动态的**（⑤19:18、21:10）：原油没突破就说没到——"你没有把盒子打开，行情没有告诉你破盒而出，你就不知道到了"；"没开盒之前，都只是动态的变化"。同理未出场前盈亏未定，提前下爆亏结论并割肉=自己开盒确认亏损。
42. **目的是赚钱，不是为了赌看法**（⑤20:44）：纳指看对了但没买上，"看对看错还有什么意义"；看法错了但过程中赚到了钱，也是好操作——"赌没有任何意义，赌赢了又如何"。
43. **跟单陷阱：广撒网、补的是下一条鱼**（⑤04:04）：散户把身家性命交给博主，或观察哪位博主在上一批走势里活到最后、心理价值提升，再把下一笔趋势投给他——"你做的永远是下一单"，用历史胜率评估下一单，必定有赚有赔。
44. **利润转移：杠杆赚满→无杠杆博可能性**（⑤05:32、07:37）：年初杠杆暴赚（暴跌暴涨全做、一笔几百点）后主动转无杠杆，"把杠杆赚的盆满钵满投入到无杠杆，用可控的回撤博未来的可能性"；同笔资金留在杠杆"可能就全部亏回去"。配套心态："做得好连赚时一定要赚出多的，才能面临后续亏的"。
45. **仓位配比（半年最终版）**（⑤08:15、18:19）：黄金+白银合计 **50-55%**（亏得最少因为买价好：均价4300跌到3800-3900，约10%完全可接受，而非34%仓冒20%风险）；黄金30%+10%加仓≈3/4仓；白银一笔拆三笔各1/3；原油现持60%、剩40%等震荡完下探再补，均价保持80下方；五粮液110起买、70附近加仓一倍。
46. **波动差异决定资金分配**（⑤08:55）：白银波动远大于黄金——"黄金亏2.5%，白银就要亏5%-8%"，120腰斩才几天；黄金的资金量不能套用到白银，否则亏损成倍。黄金反而在众品种中最稳定（高点跌30% vs 科技股腰斩再腰斩），跌30%意味着再涨回去可赚40%，"花时间就可以赚到钱"。
47. **拆分买入好过一次性无限套牢**（⑤09:52）：白银拆1/3×3的理由——没破前高前可能继续破前低但"价格差不太多"，拆分后即使再破前低仍有弹药，"好过全部买进以后无限套牢"。
48. **阴跌收敛 vs 跳水暴跌，两种走势**（⑤10:10）：跌得越来越少、拖得越来越长 → 转化为波动越来越小的压缩走势，趋于平静后"爆发向下的概率远低于爆发向上"；另一种是慢速下跌后突然跳水。前者是他敢于低位持有等爆发的依据。
49. **买在下跌尾声博下轮启动**（⑤16:02、16:51）：核心买点哲学——"不是在这买的，是在下跌尾声买的"；"与其在下跌尾声中的尾声去割肉，不如等它下轮启动"。高位买进面临的是长时间调整；调整末段买进，搏的是下一轮启动。
50. **望远镜角度 vs 放大镜角度**（⑤17:03）：没有望远镜的角度思考战略位置，只把放大镜对准眼前走势的得失，必然陷入"亏了要不要割肉、搏快速上涨结果慢速下跌怎么办"的纠结。
51. **茅台短线 vs 五粮液长线，同行业两笔交易**（⑤14:50）：茅台有明确分水/指引位/止损位，"到这一线就回调、到这一线就涨"——次低买进做快速短线，赚20-30%就减仓；五粮液做长线博一倍两倍。两笔出场逻辑不同"不是因为他套住了，是在战略角度里所处阶段不同"。
52. **满仓单品种=自造暴涨暴跌**（⑤21:20）：满仓梭哈黄金，等于"把它从一个稳定品种变成一个暴涨暴跌品种"；满仓后"买进以后再也没有机会补仓、没有办法调整"，说明一开始就买得过大了。
53. **散户怪圈：给机会不买、没机会想买**（⑤22:12）：买不对就割肉、割完不再买，涨起来再追没机会；突破后想等3700回踩，"回头只会给你4800"；从5600没买到3700，突破后再回头也买不到了——"你基本上90%看不到行情到六千点，等到了六千你仍然看不到七千"。
54. **散户的钱大于时间**（⑤23:10）：没有用很短时间赚更多钱的能力，就"优先花时间赚米"；珍惜4000附近的筹码位——向下空间仍然小、向上空间仍然大。

## 九、每期复盘的固定模板（①②④的节目结构）

按品种逐一过：**黄金 → 白银 → 原油 → 纳指 → 比特币 → 大盘 → 个股（茅台/五粮液）**，
每个品种说三件事：
1. 当前分水岭价位在哪里、过了没有
2. 剧本A（突破→持有/加仓）/ 剧本B（没突破→下来到某价位补多少）各自怎么执行
3. 当前仓位状态与下一步动作（带保本/减仓/等待）

## 十、对接 pattern-scan 的改进清单

| 他的手法 | 工具化方向 |
|---|---|
| 分水岭判定（前高/前低水平线） | 自动识别前高前低；统计匹配段后续"突破/跌破分水岭"的概率与时点 |
| 大跌大弹规律 | 统计"跌破前低后 N 根内的反弹幅度分布"——量化破位后该等反弹而不是割肉 |
| 两种上涨的区分 | 相似度中加入上涨速度（斜率/耗时）特征维度 |
| 止跌确认 | 统计匹配段"首次止跌企稳（连续N根不创新低）"的时点分布 → 对应入场纪律 |
